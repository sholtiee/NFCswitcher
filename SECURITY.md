# Security Policy

NFCswitcher interacts with low-level NFC behavior on rooted Android devices. Treat every build as experimental.

## Reporting Issues

Please open a GitHub issue for:

- crashes;
- device-specific NFC HAL incompatibilities;
- incorrect root detection;
- unsafe behavior during mode switching;
- documentation gaps.

Do not submit real payment card numbers, access-card credentials, private keys, or personal identifiers in logs or screenshots.

## Responsible Use

Use this project only with tags, devices, and profiles you own or are authorized to test.
